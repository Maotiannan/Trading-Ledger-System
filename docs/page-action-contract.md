# 页面操作与付款记录

| 页面 | 操作口径 |
| --- | --- |
| 账单 | MU Contract 来源行可改订单号、账单号与金额。客户资料只读；联系方式在客户管理维护，换绑客户须走来源对账。手工账单仍按原规则编辑。 |
| 付款明细 | 已收款不能编辑或申请删除；银行转账阶段不能申请删除。 |
| SWIFT | 水单或所属明细已签收时不能编辑。 |
| 收据 | 普通 Bank_Transfer 收据不能直接改或申请修改。系统转移仍走原有撤销入口。 |
| 审批 | 申请后原单进入锁定状态，管理员仍可拒绝并关闭申请，但不能批准修改；拒绝不改变原单。审批失败会提示，可刷新核对。 |
| 付款历史 | 账单与 Dashboard 共用同一个付款记录弹窗和分页接口，超过 30 笔仍可翻页。加载失败可重试，只有查询成功且无记录才显示空状态。 |
| 客户 | 编辑普通资料不会修改默认收货人；现有收货人的增删和设默认统一由 CONSIGNEE 管理处理。新建客户可填写初始收货人。 |
| 设置 | SWIFT 手续费仍按每张上限计算；已停用的两项容差不再展示或接受写入。OCR 测试使用已保存配置，OCR 配置有改动时需先保存。 |

不新增数据库字段、后台作业或文件，没有回填或重算。现有数据库及媒体的[备份与恢复范围](backup/muledger-local-backup.md)不变。
