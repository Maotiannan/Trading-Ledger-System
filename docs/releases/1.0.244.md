# MuLedger 1.0.244

- Receipt and payment-detail edit approvals compare the request baseline with the locked record. A conflict leaves the request pending, shows the original, requested and current fields, and can still be rejected. Duplicate decisions cannot repeat the business action.
- Edit reviews, deletion decisions, account creation, role changes and administrative password resets commit their strict audit with the business change.
- Local backup retention distinguishes an already-removed expired SMB directory from a failed mount or inaccessible current snapshot. A cleanup failure never invalidates an already published backup or retries the full export.
- Adopted fixed-image sites can preflight, release and roll back from main. Existing release chains still require their recorded first-cutover procedure. See [fixed-image releases](../pinned-site-release.md) and the [backup runbook](../backup/muledger-local-backup.md).

No database migration, historical data repair, additional notification sending, or change to storage scope. Preparing or building this release does not deploy it.
